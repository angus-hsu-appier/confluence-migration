# Attachments to download manually

Confluence MCP can't download binary attachments, so you need to save these from Confluence by hand. Steps for each entry:

1. Open the original Confluence page (link in **Source** column).
2. Right-click the image → **Save image as...**
3. Save with the filename listed in **Target file** below.
4. Place it in `docs/idash/iTest/assets/`.

When done, delete this file.
