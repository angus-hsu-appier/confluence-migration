# Attachments to download manually

Confluence MCP can't download binary attachments. Save these images by hand:

1. Open the source page (link in the table).
2. Right-click the image → **Save image as...**
3. Save with the filename listed in **Target file**.
4. Place it in `docs/qa-team/study-group/assets/`.

Delete this file when all images are in place.
